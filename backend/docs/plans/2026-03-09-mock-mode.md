# Mock Mode Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a backend-wide mock mode that starts locally without MySQL and supports authenticated mock API usage.

**Architecture:** Introduce `APP_MODE=mock` as the single switch for startup, auth, and router selection. Keep MySQL behavior unchanged in normal mode, but in mock mode bypass DB initialization and provide mock auth/current-user plumbing so protected mock routes remain usable.

**Tech Stack:** FastAPI, SQLAlchemy, Pydantic, TestClient, JSON-backed mock stores
