# 升降机专项故障诊断 Skill

## 能力说明

本 Skill 专注于汽车总装产线**升降机**（含 EL 系列：升降台、随行升降机、接车升降机）的故障分析，执行以下推理步骤：

1. **设备识别** — 识别升降机编号、位置、类型（随行/固定/接车）
2. **故障分类** — 机械故障（联轴器/链条/导轨/配重）/ 电气故障（变频器/传感器/限位/接触器）/ 控制故障（PLC/HMI/通信）
3. **根因定位** — 结合 8D 历史案例库，优先匹配已知故障模式
4. **安全评估** — 判断是否涉及人员安全风险（高位失重、坠落），给出紧急程度
5. **处置方案** — 分临时遏制措施和长期根治措施，给出标准操作步骤
6. **8D 建议** — 给出填写 8D 报告的关键要素建议
