# 本体场景卡片：设备故障诊断

## 业务用途

建立设备故障诊断知识规则与模型，帮助用户快速排查并解决设备故障问题，提高诊断准确率，降低设备售后运维成本。

## 核心对象定义

- **现象级问题**：顶层故障问题
- **子现象**：现象级问题下的细分故障现象
- **排查点**：针对现象级问题或者子现象的排查操作
- **原因**：故障产生的原因
- **解决方案**：故障点解决方案
- **部件**：故障涉及到设备部件

## 关键关系

**包含：**

- 现象级问题 → 包含 → 子现象
- 子现象 → 包含 → 子现象

**发现：**

- 排查点 → 发现 → 子现象

**位于：**

- 子现象 → 位于 → 部件
- 排查点 → 位于 → 部位

**需排查：**

- 现象级问题 → 需排查 → 排查点
- 子现象 → 需排查 → 排查点

**其原因是：**

- 子现象 → 其原因是 → 原因

**其解决方案是：**

- 原因 → 其解决方案是 → 解决方案
- 子现象 → 其解决方案是 → 解决方案

## 事件触发

- **输入**：现象级问题（如"W轴限位报警"）
- **输出**：排查点（如"检查工艺参数是否设置焦点过大，超出调焦范围"）

## 动作规划

### 采集设备参数

- **目的**：自动采集设备参数，在解决问题的前提下，减少用户对话次数，优化用户体验，使产品更加智能。
- **触发时机**：用户提出现象级问题或子现象时。

## 场景案例

> 场景：某制造企业启动A型激光切割机时，出现了W轴限位报警，于是使用设备厂家提供的AI智能故障问诊应用排查问题。

### 1. 用户提问

> A型激光切割机开机时提示W轴限位报警

### 2. 故障诊断智能体（内部机制）

检索基于本体的知识图谱：

```
W轴限位报警
  └─ 包含 → 开机就报
       └─ 需排查 → IO端口中的"W正限位""W负限位"是否与图片中一致，注意数字部分背景色为紫色
            └─ 发现 → IO点位没有紫色背景色
                 └─ 其解决方案是 → 修改点位的常闭常开状态，将点位改回常闭状态后保存即可
```

同步采集A型激光切割机的参数（IO点位背景色 ≠ 紫色）

**得出结论**：修改点位的常闭常开状态，将点位改回常闭状态后保存即可。

### 3. 故障诊断智能体（输出答案）

> 修改点位的常闭常开状态，将点位改回常闭状态后保存即可。

### 4. 效果追踪

| 角色 | 效果 |
| --- | --- |

| 设备使用方 | 提升效率：大部分故障问题可以快速排查并解决问题 |
